# Reed-Solomon String Encoder/Decoder (Frontend)

A **modern React + TypeScript frontend** for encoding and decoding strings using **Reed-Solomon error correction**.  
Users can mark missing characters in the original string with `_`, and the app will reconstruct the original string using the parity bytes generated by the backend.

---

## Demo URL
[https://rescue-words.netlify.app](https://rescue-words.netlify.app)

---

## Features

- Encode any string into an **original + parity string**.  
- Edit original string and mark missing characters using `_`.  
- Decode to **recover the original string**, even if some characters are missing.  
- **User-friendly UI** with clear separation between editable original and parity.  
- Responsive and modern design with plain CSS (no Tailwind).  
- Works with both **development** and **production** backends via environment variables.

---

## Tech Stack

- **Frontend:** React, TypeScript  
- **Styling:** Plain CSS for modern UI  
- **API Requests:** Fetch API  
- **Environment Variables:** Vite (`.env` for dev, `.env.production` for production)

---

## Setup & Installation

1. **Clone this repository**

```bash
git clone https://github.com/kaustubh-vats/rescue.git
cd rescue
```

2. **Install dependencies**

```bash
npm install
```

3. **Configure environment variables**
    - Create a `.env` file in the root directory for development:

    ```
    VITE_API_BASE=https://rescue-backend.vercel.app
    ```

4.  **Run the development server**

```bash
npm run dev
```
